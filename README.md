# Projekt Schiffe versenken

Ein sprachgesteuertes Webspiel, das im Rahmen meiner Seminararbeit konzipiert und prototypisch umgesetzt wurde. 
Das Projekt basiert auf dem klassischen Spiel **Schiffe versenken** und ermöglicht es per Spracheingaben zu spielen.

## Verwendete Technologien

- TypeScript
- HTML und CSS
- Node.js
- Express

## Voraussetzungen

- Node.js und npm

## Installation und Start

Repository klonen und Abhängigkeiten installieren:

```bash
git clone https://github.com/Minetac/schiffe_versenken.git
cd schiffe_versenken
npm install
```

Projekt kompilieren und starten:

```bash
npm run build
npm start
```

Das Spiel kann dann im Browser per localhost gespielt werden.

## Hinweis
Die Spracheingabe wird über die Speech Recognition API des Browsers realisiert. Die Unterstützung hängt vom verwendeten Browser ab.
